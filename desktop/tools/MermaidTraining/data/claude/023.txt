コールセンターに電話が入ると、自動音声が用件の番号を聞きます。1番なら注文窓口、2番なら修理窓口につなぎます。それ以外の番号が押されたら、もう一度案内を流します。
---
flowchart TD
    A["コールセンターに電話が入る"] --> B["自動音声が用件の番号を聞く"]
    B --> C{"押された番号は？"}
    C -->|"1番"| D["注文窓口につなぐ"]
    C -->|"2番"| E["修理窓口につなぐ"]
    C -->|"それ以外"| F["もう一度案内を流す"]
    F --> B

=== flowchart
ネットショップの注文処理
1. 注文を受け付ける
2. 決済サービスで支払いを確かめる
3. 支払いが確認できない注文は取り消す
4. 確認できた注文は倉庫に回す
5. 発送したらお客様にメールする
---
flowchart TD
    A["注文を受け付ける"] --> B["決済サービスで支払いを確かめる"]
    B --> C{"支払いが確認できた？"}
    C -->|"いいえ"| D["注文を取り消す"]
    C -->|"はい"| E["倉庫に回す"]
    E --> F["発送"]
    F --> G["お客様にメールする"]
