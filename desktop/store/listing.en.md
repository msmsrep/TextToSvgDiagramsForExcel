## Product name

Text-to-SVG Diagrams for Excel

## Description (up to 10,000 characters)

```text
Draw flowcharts, sequence diagrams, ER diagrams, Gantt charts and more from Mermaid text, and insert them into your Excel sheets.

As you type the code, the preview next to it updates. Insert the result at the active cell as a PNG, JPEG or SVG image, or as shapes you can edit in Excel. Each inserted diagram keeps its Mermaid code, so later you just select it on the sheet to load it, fix it and replace it.

KEY FEATURES
• Live preview as you type, with the line of a syntax error highlighted and one click to jump to it
• Five ways to insert: PNG / JPEG / SVG / SVG for shape conversion / Excel shapes (flowcharts become editable shapes and connectors)
• Edit inserted diagrams again: select one on the sheet to load it, then replace it in the same place, with the same name and size
• Build diagrams from the selected cells: flowcharts (parent, child), Gantt charts (task, start, end or days) and pie charts (label, value)
• Nine templates: flowchart, sequence, class, state, entity relationship, Gantt, pie, mindmap and timeline
• Choose the output size as a percentage or a width in points; save image files or copy to the clipboard
• Open and save .mmd files
• Keep the window on top to work side by side with Excel
• English and Japanese user interface

PRIVACY
Diagrams are drawn entirely on your PC. Your code and cell values are never sent anywhere, and the app works offline.

WORKS WITH THE ADD-IN
The app is compatible with the Office add-in of the same name: diagrams inserted with either one can be loaded and replaced with the other.

REQUIREMENTS
• Windows 10 version 2004 or later, or Windows 11 (x64 / Arm64)
• Excel 2016 or later for desktop (SVG insertion needs a version of Excel that supports SVG)
• Microsoft Edge WebView2 Runtime (included in Windows 11)

Mermaid is the name of the Mermaid project. This app is an unofficial tool and is not affiliated with the Mermaid project or Microsoft.
```
