# Text-to-SVG Diagrams for Excel 今後の予定

未実装の機能追加候補をまとめる。現行の仕様は [specification.md](./specification.md) を参照。

優先して検討する順は **5**。

## Excel 連携

選択セルからのコード生成（旧 1）とシート上の図形選択での自動読み込み（旧 3）は実装済み（仕様書 §4.10、§4.3）。

### 2. セル値の差し込み（プレースホルダ）

コード中の `{{Sheet1!B2}}` のような記述を、描画時にセルの値へ置き換える。

### 4. 一括再描画

シート（またはブック）内の Mermaid 図を、代替テキストに保存したコードからまとめて描き直す。テーマ変更・mermaid 更新後や、2 と組み合わせたデータ更新時に使う。

## 使い勝手

テンプレート挿入（旧 7）は実装済み（仕様書 §4.13）。

### 5. テーマ・見た目の設定

テーマ（default / dark / forest / neutral）、背景色、フォントを選べるようにする。現状は `theme: "default"` 固定。

## 小改善

- 図に任意の名前を付ける（ドロップダウンの表示名）
- ブック全体の図一覧（現状はアクティブシートのみ）
- コードのクリップボードコピー、`.mmd` の保存・読み込み
- 入力欄のシンタックスハイライト

## 検討事項

- 設定（5、および実装済みの出力サイズ）の保存先。出力サイズ（仕様書 §4.12）は現状保存せず、開くたびに既定値に戻る。プライバシーポリシーで「ローカルストレージ不使用」と明記しているため、`Office.context.document.settings`（ブック内に保存）を使うか、ポリシーを改訂するかを決める。
