=== sequence
The mobile app sends a search query to the API gateway. The gateway forwards it to the search service, which returns a list of results. The gateway passes the results back to the app.
---
sequenceDiagram
    participant M as Mobile app
    participant G as API gateway
    participant S as Search service
    M->>G: Search query
    G->>S: Forward the query
    S-->>G: List of results
    G-->>M: Results

A user requests a report from the web app. The web app puts a job on the queue, and the worker picks it up. The worker reads the data from the warehouse, builds the report, and stores it in the file store. The worker notifies the web app, and the web app emails the user a link.
---
sequenceDiagram
    participant U as User
    participant W as Web app
    participant Q as Queue
    participant K as Worker
    participant D as Warehouse
    participant F as File store
    U->>W: Request a report
    W->>Q: Put a job on the queue
    Q->>K: Job
    K->>D: Read the data
    D-->>K: Data
    K->>F: Store the report
    K->>W: Notify
    W->>U: Email a link
