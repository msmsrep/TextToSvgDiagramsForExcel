=== sequence
The user asks the app to open a file. The app requests the file from the cloud drive. If the user has access, the drive returns the file and the app shows it. Otherwise the drive returns an error and the app shows an "access denied" message.
---
sequenceDiagram
    participant U as User
    participant A as App
    participant D as Cloud drive
    U->>A: Open a file
    A->>D: Request the file
    alt User has access
        D-->>A: File
        A-->>U: Show the file
    else Otherwise
        D-->>A: Error
        A-->>U: Access denied
    end
=== sequence
A guest asks the front desk for a late checkout. The front desk asks housekeeping whether the room is needed. If it is not needed, housekeeping agrees and the front desk confirms to the guest. If it is needed, the front desk offers the guest the lounge instead.
---
sequenceDiagram
    participant G as Guest
    participant F as Front desk
    participant H as Housekeeping
    G->>F: Ask for a late checkout
    F->>H: Is the room needed?
    alt Not needed
        H-->>F: Agree
        F-->>G: Confirm
    else Needed
        H-->>F: Room is needed
        F-->>G: Offer the lounge instead
    end

    end

=== sequence
A customer asks the waiter whether the soup contains nuts. The waiter asks the chef. If it does, the chef says so and the waiter suggests another dish. If it does not, the waiter tells the customer it is safe.
---
sequenceDiagram
    participant C as Customer
    participant W as Waiter
    participant K as Chef
    C->>W: Does the soup contain nuts?
    W->>K: Ask
    alt Contains nuts
        K-->>W: Yes
        W-->>C: Suggest another dish
    else No nuts
        K-->>W: No
        W-->>C: It is safe
    end

    alt Reversal succeeds
        N-->>P: Confirm
        P-->>M: Refund is done
    else Reversal fails
        N-->>P: Failure
        P-->>M: Retry later
    end

=== sequence
The vending kiosk sends a card payment to the acquirer. The acquirer asks the issuer to authorize it. If the issuer declines, the acquirer returns "declined" and the kiosk asks the customer for another card. If the issuer approves, the kiosk dispenses the item to the customer.
---
sequenceDiagram
    participant C as Customer
    participant K as Vending kiosk
    participant A as Acquirer
    participant I as Issuer
    K->>A: Card payment
    A->>I: Authorize
    alt Issuer declines
        I-->>A: Decline
        A-->>K: Declined
        K->>C: Ask for another card
    else Issuer approves
        I-->>A: Approve
        A-->>K: Approved
        K->>C: Dispense the item
    end
